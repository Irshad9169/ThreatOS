import redis, json
r = redis.Redis(host='localhost', port=6379, decode_responses=True)
r.xadd('threatos:events:normalized', {
    'event_id': 'test-001', 'log_source': 'winlog',
    'host': 'WIN-DC01', 'process': 'powershell.exe',
    'command_line': 'powershell -EncodedCommand abc',
    'raw_fields': json.dumps({'process':'powershell.exe'}),
})
print('Done')
"

What Remains for True Enterprise Grade
The items below were designed but not yet implemented — they require external infrastructure decisions:
HTTPS              → Need internal CA cert from your IT team
PgBouncer          → Install pgbouncer, set PGBOUNCER_MODE=true in .env
Prometheus scrape  → Install Prometheus + Grafana, point at /metrics
Real log connectors → WEF forwarder or syslog receiver
Ticketing          → Jira/ServiceNow webhook on high-risk alerts
Backup             → pg_dump cron to /backup/ or S3
All the backend hooks are in place — /metrics is live, PGBOUNCER_MODE flag exists in database.py, health checks run automatically. You just need the external tools pointed at the right endpoints.
