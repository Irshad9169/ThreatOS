2. Backup
Zero backup exists. If the disk fails everything is gone — 2,662 rules, all audit logs, all alerts.
bash# Add this cron job right now — takes 30 seconds
mkdir -p /backup/threatos
cat > /etc/cron.d/threatos-backup << 'EOF'
0 1 * * * root pg_dump -h localhost -U threatos threatos | \
  gzip > /backup/threatos/db_$(date +\%Y\%m\%d).sql.gz && \
  find /backup/threatos -name "*.sql.gz" -mtime +7 -delete
EOF

3. Firewall rules
Port 8001 (API) should not be publicly accessible — only port 8080 (nginx) should be open. The API port exposes the raw FastAPI including /metrics and /health without any network-level protection.
bashsudo firewall-cmd --permanent --add-port=8080/tcp
sudo firewall-cmd --permanent --remove-port=8001/tcp
sudo firewall-cmd --reload
